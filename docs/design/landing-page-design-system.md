# TempoTune 랜딩 페이지 디자인 시스템

- 상태: 적용 완료
- 기준일: 2026-08-19
- 작성 범위: 웹 랜딩 페이지와 공용 브랜드 표현
- 근거: 현재 제품 코드, 핵심 기능 품질 계약, 1440×900·390×844 전체 화면 캡처

## 문제와 목표

기존 랜딩 페이지는 현재 제공하지 않는 가격, 로그인, 클라우드 동기화, 데스크톱 네이티브 앱과 앱 스토어 배지를 노출합니다. 핵심 기능보다 빈 장식 화면이 크게 보이고, 데스크톱에서는 제목의 한국어 단어가 중간에 끊깁니다. 앱 아이콘과 랜딩 로고의 모양도 서로 다릅니다.

새 랜딩은 사용자가 첫 화면에서 TempoTune의 용도와 신뢰 근거를 이해하고, 메트로놈이나 튜너를 바로 실행하도록 돕습니다. 제품에 이미 구현된 기능만 말하며 앱 아이콘, Lucide 아이콘, 색상 토큰을 한 체계로 묶습니다.

## 대상 사용자와 주요 과업

주 대상은 연습을 시작하기 전에 빠르게 박자나 음정을 맞추려는 연주자입니다. 방문자는 다음 순서로 판단합니다.

1. 이 제품이 메트로놈과 튜너를 제공하는지 확인합니다.
2. 정확도를 믿을 만한 근거가 있는지 살펴봅니다.
3. 설치나 가입 없이 웹 도구를 실행합니다.
4. 필요하면 리듬 연습과 설정 기능을 더 확인합니다.

## 제품 범위

### 포함

- 메트로놈, 튜너, 리듬 연습, 설정으로 연결되는 실제 경로
- 메트로놈 6시간 누적 오차 회귀와 튜너 35–1400Hz·5 cents 기준
- 웹과 iOS·Android 하이브리드 구조
- 라이트·다크 테마, 키보드 포커스, 44px 이상 주요 터치 영역
- 1440×900과 390×844 전체 화면 검증

### 제외

- 가격, 로그인, 커뮤니티, 소셜 채널
- 앱 스토어 다운로드 링크와 데스크톱 네이티브 앱
- 클라우드 동기화와 검증되지 않은 사용자 수
- 구현되지 않은 폴리리듬, 라이브러리, 고급 설정

3. 검증 스트립: 6시간, 35–1400Hz, 5 cents
4. 핵심 도구: 메트로놈, 튜너, 리듬 연습, 설정
5. 정확도 설명: 시간 누적 오차와 수음 정확도를 짧게 설명
6. 마지막 CTA와 실제 경로만 있는 푸터

## 시각 원칙

### 성격

TempoTune은 공연 포스터보다 정밀 계측기에 가깝게 보입니다. 넓은 여백, 큰 수치, 정돈된 그리드와 제한된 청록색 강조를 사용합니다. 장식용 그래디언트는 배경 깊이를 만드는 범위에서만 씁니다.

### 색상

기존 제품 토큰을 단일 기준으로 유지합니다.

| 역할        |    라이트 |      다크 | 사용처                      |
| ----------- | --------: | --------: | --------------------------- |
| Primary     | `#1d7874` | `#58b09c` | CTA, 활성 상태, 정밀도 강조 |
| Background  | `#fcfaf3` | `#0c252b` | 페이지 바탕                 |
| Deep        | `#f4f1de` | `#071e22` | 대비 섹션, 프리뷰           |
| Surface     | `#ffffff` | `#16323f` | 카드                        |
| Strong text | `#071e22` | `#f4f1de` | 제목과 핵심 수치            |
| Muted text  | `#61767e` | `#90aba8` | 보조 설명                   |

한 화면에서 Primary 외에 별도 강조색을 추가하지 않습니다. 위험 상태에만 기존 danger 토큰을 씁니다.

### 타이포그래피

- 영문 수치와 브랜드: Space Grotesk
- 한국어 본문: Noto Sans KR 폴백
- 히어로 제목: 데스크톱 68–80px, 모바일 42–48px, 줄 높이 1.02–1.08
- 섹션 제목: 데스크톱 40–52px, 모바일 30–36px
- 본문: 16–18px
- 보조 텍스트: 최소 12px
- 한국어 제목에는 `word-break: keep-all`을 적용합니다.

### 간격과 형태

- 본문 최대 폭: 1200–1280px
- 섹션 세로 간격: 데스크톱 112–144px, 모바일 72–96px
- 카드 모서리: 20–28px
- 버튼 모서리: 12–14px
- 선: 1px, 기본 border 토큰 사용
- 그림자: 프리뷰와 고정 헤더에만 낮은 농도로 사용

## 아이콘과 에셋

- 브랜드 마크는 `public/icon-192.png`를 사용합니다. 다른 음표 로고를 만들지 않습니다.
- 기능 아이콘은 Lucide 한 세트로 통일하며 `absoluteStrokeWidth`, 2px 선 두께를 유지합니다.
- 아이콘은 20px 또는 24px를 기본으로 하고 기능 카드만 26–28px를 허용합니다.
- 같은 의미에는 같은 아이콘을 씁니다. 메트로놈은 `Timer`, 튜너는 `AudioLines`, 리듬은 `Activity`, 설정은 `SlidersHorizontal`을 사용합니다.
- 장식 이미지를 추가하기보다 실제 앱의 수치, 게이지, 박자 표시를 단순화한 CSS 프리뷰를 사용합니다.

## 반응형 규칙

- 768px 미만에서는 헤더 앵커를 숨기고 브랜드와 실행 버튼만 남깁니다.
- 히어로는 모바일에서 단일 열이며 제품 프리뷰를 CTA 아래에 둡니다.
- 검증 수치는 모바일에서 한 열로 배치해 수치와 설명을 함께 읽을 수 있게 합니다.
- 기능 카드는 모바일 1열, 태블릿 2열, 데스크톱 4열입니다.
- 가로 스크롤을 허용하지 않습니다.
- 움직임 감소 설정에서는 부유·맥박 애니메이션을 끕니다.

## 문구 원칙

- 확인된 기능과 수치만 적습니다.
- “완벽한”, “초정밀”, “프로를 위한”처럼 근거 없는 최상급을 쓰지 않습니다.
- CTA는 행동 결과를 그대로 표현합니다: “메트로놈 열기”, “튜너 열기”.
- 기술 명칭보다 사용자 결과를 먼저 말하고, 수치 근거는 바로 옆에 둡니다.

## 수용 기준

- 1440×900과 390×844 전체 화면에서 잘림, 가로 스크롤, 한국어 단어 분리가 없습니다.
- 헤더와 본문의 모든 버튼·링크가 실제 경로나 앵커로 이동합니다.
- 앱 스토어, 로그인, 가격, 클라우드 동기화, 사용자 수 문구가 없습니다.
- 앱 아이콘과 기능 아이콘이 위 규칙을 따릅니다.
- 라이트·다크·시스템 테마에서 대비와 정보 위계가 유지됩니다.
- 키보드 포커스가 보이고 주요 터치 대상은 44px 이상입니다.
- 랜딩 E2E, 테마 E2E, 타입 검사, 린트, 빌드가 통과합니다.
